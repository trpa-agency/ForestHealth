# plot-network-design

Sampling frame, weights, and GRTS site selection for TRPA's forest health plot network (VP9 seral and canopy cover, VP10 stand density). Output is the plot location layer, allocation table, backup list, and installation order the field-only RFP references. Site list freezes at contract execution (December 2026).

LiDAR base products (CHM, DTM, 30 m metrics, TAOs) are NOT built here. They come from `trpa-agency/general-purpose/lidar-2022` and are read from `\\vcenter2\GIS_DATA\LiDAR\2022\Derived` through `sources:` in `config.yaml`. If a metric is missing or wrong, fix it there and rerun; do not recompute LiDAR metrics in this folder.

Sample design is Andy McClary's from Sept 24 2026. Start at `notebooks/00_sample_design_template.ipynb` (built by `scripts/build_sample_design_template.py`) and `docs/SAMPLE-DESIGN-2026-10-19.md` (current design; the Sept 24 handoff still covers run order and data access). Data comes from SDE and the threshold project gdb (`sde:` in config), not REST.

Read first: `docs/SAMPLE-DESIGN-2026-10-19.md` (the design), `README.md` (what is in the folder), `docs/METHODS.md`. `PLAN.md` is the Sept 5 plan, kept as history.

## Layout

- `config.yaml` - every source path, threshold definition, break, floor, share, and seed. Nothing is hardcoded.
- `src/strata.py` - forest type mapping, class assignment, cell collapse, allocation candidates, Python GRTS, installation order. `src/qa.py` - checks and the QA report. `src/layers.py` - file or TRPA REST reads. `src/io.py` - config and logging.
- `notebooks/00_sample_design_template` - the sample design, generated by `scripts/build_sample_design_template.py`: edit the builder, regenerate, do not hand-edit `.ipynb`. The old 01 to 04 chain is in `archive/split-sample-2026-09/`.
- `notebooks/06_tessellation` - the Basin wide extension of the CSO owl grid for Pat Manley and Shale Hunter, and the sample design grid that shares its centres. Pure arcpy `GenerateTessellation`; `src/tessellation.py` supplies the lattice fit. Generated by `scripts/build_tessellation_notebook.py`, same rule. Writes `outputs/tessellation.gdb`, shapefile and GeoPackage copies, and `outputs/tessellation_summary.json`, which `scripts/build_html_data.py` reads for `html/`.
- `scripts/grts_select.R` - the frozen spsurvey selection, called by section 5 of the template.
- `data/`, `outputs/`, `logs/` are gitignored.

## Runtime

- Env: `arcgispro-py3` plus `pyyaml`, `python-dotenv`. R 4.x with `spsurvey`, `sf` for the frozen draw.
- Runs on a workstation or the GIS server; reads from the share and TRPA REST services. SDE connections in `F:\GIS\DB_CONNECT` are READ ONLY.
- Status: chain verified end to end on the synthetic Basin only; `run.synthetic` is still `true`. Real layers need the REST URLs wired into `sources:` and the lidar-2022 products published.

## Before the real run

1. lidar-2022 has published `Derived\metrics_30m`, `chm_1m_tiles`, `dtm_1m_tiles`, and `taos`.
2. `crs.lidar_grid_m` and the product grid match Shengli's covariate grid (set in lidar-2022 before its heavy pass).
3. `sources:` REST URLs for CWHR, urban boundary, wilderness, roads, trails, streams, structures, parcels, ownership, state line, treatments, and fire severity.
4. `threshold.tpa_dbh_floor_in` confirmed with Shengli; `strata.height_breaks_m` and `density_breaks` calibrated (see `archive/split-sample-2026-09/notebooks/02_strata.ipynb`) once plots with both QMD and LiDAR exist.
5. `run.synthetic: false`; `run.freeze: true` only for the selection frozen at contract execution, with `draw.seed` recorded.

## Design decisions (do not silently undo)

Current design: `docs/SAMPLE-DESIGN-2026-10-19.md` (Mason and Andy, Oct 19 2026). In short:

- Estimator is model-assisted with 2022 LiDAR as the auxiliary; 40 per type is enough only on that basis.
- Population is the report frame (115,396 ac). Sampling frame is public land only (`frame.public_owner_values`), 30 m off private parcels, roads, trails, streams, and structures. No slope cut.
- Forest type is the only stratum. One spsurvey GRTS selection (`scripts/grts_select.R`), `seltype = "proportional"` on `mult` = 1.5 on RRK tail cells x 0.5 on centre slope over 50 percent. No split sample, no disturbance weights, no legacy sites, no cell collapse or per-cell allocation.
- Minimum 40/40/40; full 70/40/40 is the minimum plus the next 30 SMC sites in order. Ranked list is 3x the full target per type. A rejected site is replaced by the next unused rank in its type; a design coordinate is never moved.
- Basin side and TPI are reported (realized vs expected), not forced: spsurvey `caty_n` sets expected counts only.
- Access class is hike distance to a drivable road, breaks 0.5 and 1.5 miles. `draw.min_distance_m` is 100.
- The sampling unit is a 3 by 3 block of 30 m pixels, plot on the centre pixel. The plot is the status plot (quarter acre, all trees 4.0 in and up), protocol not design.
- Freeze at contract execution (December 2026), seed recorded. Python GRTS is iteration only.
- `threshold:` values match the threshold report; do not edit without a citation. The blind remeasure flag is stripped from the published layer (`run.publish_strip_fields`).
- TEON MSIM and LTUB sites never enter the sample. Do not add `teon_sites_100` to `legacy_sources`.
- The owl grid is one exact lattice only in NAD83 UTM 10N (400 ha flat top hexagons, residual under 5 mm over all 8,087 cells). `tessellation.epsg` stays 26910; the sample design grid is the ratio 3 transverse hexagon anchored on the same corner, so every owl centre is a fine centre. Do not fit or extend it in California Albers, and do not add a parent cell field: hexagons never nest, plots aggregate to owl cells by location.
