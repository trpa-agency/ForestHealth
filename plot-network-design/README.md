# plot-network-design

Sampling frame, strata, nested allocation, and GRTS site selection for TRPA's forest health plot network: VP9 (seral stage and canopy cover, 75 percent standard) and VP10 (stand density, 50 percent standard) on the 115,396 acre conifer frame, by forest type. The outputs are the plot location layer, the allocation table, the backup list, and the installation order the field only RFP references. Lead: Andy McClary. Protocol and RFP: Mason Bindl. Read `docs/HANDOFF-ANDY-2026-09-24.md` for what is settled and what is yours to decide.

## Start here

`notebooks/00_sample_design_template.ipynb`, generated by `scripts/build_sample_design_template.py`. Sections 0 to 7 run the whole design from `Vector.sde` (read only), `Raster.sde`, and the threshold project geodatabase on F:, through arcpy: sources and discovery, frame, strata and covariates, allocation, selection (spsurvey through `scripts/grts_split_draw.R`, Python GRTS as the fallback), evaluation, and export. With `run.synthetic: true` it runs on any Python on a toy Basin; with `false` it needs the arcgispro-py3 interpreter, F: mounted, and Rscript on `run.rscript`.

```
python scripts/build_sample_design_template.py
python -m jupyter nbconvert --to notebook --execute --inplace notebooks/00_sample_design_template.ipynb
```

## The deeper chain

`01_frame`, `02_strata` (height to QMD calibration), `03_allocate_draw`, `04_evaluate`, from `scripts/build_notebooks.py`, one step per notebook on the same config and modules. `06_tessellation`, from `scripts/build_tessellation_notebook.py`, builds the 400 ha owl grid extension and the 133 ha sample design grid the plots are tagged with. Edit builders, never `.ipynb` files.

## Where the numbers live

`config.yaml`, and nowhere else: every source path (`sources:`, with `rrk:` and `lidar:` forms picked by `strata.source`), the threshold definitions, breaks, floors, shares, the seed, and the `# CONFIRM` placeholders for SDE class names. Methods live in `src/`: `strata.py`, `covariates.py`, `sample_size.py`, `tessellation.py`, `qa.py`, `layers.py`, `design_template.py`.

## Where outputs go

`data/processed/` for intermediates and the spsurvey inputs, `outputs/` for review tables, the QA report, `plots_design_<date>.gpkg` (public) and `_internal.gpkg`, the installation order, and the backup list, `logs/` for run logs. All three are gitignored; commit notebooks with outputs stripped.
