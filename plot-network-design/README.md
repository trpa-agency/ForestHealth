# plot-network-design

Sampling frame, weights, and GRTS site selection for TRPA's forest health plot network: VP9 (seral stage and canopy cover, 75 percent standard) and VP10 (stand density, 50 percent standard) on the 115,396 acre conifer frame, by forest type. The outputs are the plot location layer, the allocation table, the backup list, and the installation order the field only RFP references. Lead: Andy McClary. Protocol and RFP: Mason Bindl. Read `docs/SAMPLE-DESIGN-2026-10-19.md` first: it is the current design and supersedes the design sections of `docs/HANDOFF-ANDY-2026-09-24.md`.

## Start here

`notebooks/00_sample_design_template.ipynb`, generated by `scripts/build_sample_design_template.py`. Sections 0 to 7 run the whole design from `Vector.sde` (read only), `Raster.sde`, and the threshold project geodatabase on F:, through arcpy: sources and discovery, the public-land frame with buffers and access classes, structure classes and balance covariates, targets and weights, selection (spsurvey through `scripts/grts_select.R`, Python GRTS as the fallback), evaluation, and export with RFP Appendix A. With `run.synthetic: true` it runs on any Python on a toy Basin; with `false` it needs the arcgispro-py3 interpreter, F: mounted, and Rscript on `run.rscript`.

```
python scripts/build_sample_design_template.py
python -m jupyter nbconvert --to notebook --execute --inplace notebooks/00_sample_design_template.ipynb
```

## Where the numbers live

`config.yaml`, and nowhere else: every source path (`sources:`, with `rrk:` and `lidar:` forms picked by `strata.source`), the threshold definitions, breaks, floors, shares, the seed, and the `# CONFIRM` placeholders for SDE class names. Methods live in `src/`: `strata.py`, `covariates.py`, `sample_size.py`, `tessellation.py`, `qa.py`, `layers.py`, `design_template.py`.

## Where outputs go

`data/processed/` for intermediates and the spsurvey inputs, `outputs/` for review tables, the QA report, `plots_design_<date>.gpkg` (public) and `_internal.gpkg`, the installation order, the backup list, and the Appendix A tables, markdown, and frame map, `logs/` for run logs. All three are gitignored; commit notebooks with outputs stripped.

## Dates

The site list freezes at contract execution in December 2026 (`run.freeze: true`, seed recorded); nothing changes after it without restarting review. Appendix A counts post with the RFP; coordinates are furnished at execution.
