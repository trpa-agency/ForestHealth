# Changes, September 19, 2026

Implements the four decisions taken after the Pat Manley meeting. Nothing already in the repository was rewritten; the stratified allocation, cell-level GRTS, installation order, access classes, LiDAR, and TAO code all stand. What follows is new.

## New modules

**`src/sample_size.py`** produces every number in `Sample-Size-Literature-Review.md`. Two-sided CI half-width, the one-sided attainment test the standards actually pose, detectable margin at a given n, model-assisted variance reduction by 1 minus R², Kish design effect for the split sample, change detection with permanent plots, and the largest-remainder allocation. `python src/sample_size.py` prints the six planning tables.

**`src/plot_geometry.py`** is the single source of truth for the Protocol v1.0 geometry: the four sampling units, their radii, areas, and expansion factors, the breakpoint rule, and the helpers that derive transect endpoints, the 100 canopy intercept points, duff and litter points, stem positions, and ring polygons from a plot center. The canopy point layout matches the Survey123 repeat calculation exactly and the test proves it.

**`src/plot_metrics.py`** turns the Survey123 feature service tables into one row per plot visit: TPA, BA, and QMD at the 4.0 inch floor and at the FIA and MSIM floors for the baseline bridge; crown cover and effective cover from the 100 point intercept with the definitional gap and binomial SE; the crown width cross-check; seral class and the five VP9 classes; fine woody counts, duff and litter means, and CWD volume by planar intercept with the FIA slope correction. `vp10_attainment()` flags each plot against the density table from `thresholds/189-stand-density.md` in the ForestHealth repo.

**`scripts/grts_split_draw.R`** runs the split sample in spsurvey. Half A is equal probability stratified by forest type only, with legacy sites, so the population definition survives remeasurement and domain sizes are fixed. Half B is unequal probability by structural cell using `inclusion_weight`, exactly as `grts_draw.R` did. Writes `outputs/grts_split_draw.gpkg` with a `half` column, the spatial balance of each half, and the Kish design effect of the pooled primaries from the achieved weights. `grts_draw.R` is unchanged and still runs the single-draw design if needed.

**`src/covariates.py`** (added September 21) computes the balancing covariates GRTS uses through `caty_var` and `caty_n` without stratifying on them: topographic position in five classes from a TPI on the LiDAR DTM, basin side relative to the lake's long axis, the crossed `balance_caty` label, and `caty_n_by_stratum()` which turns area shares into expected counts per category inside each forest type with a floor so no occupied class is empty. `grts_split_draw.R` now runs Half A with `seltype = "unequal"` on that category and writes `outputs/grts_split_catyA_check.csv` comparing realized to expected counts.

**`scripts/build_xlsform.py`** builds `TRPA_ForestHealth_Plot_Survey123_v1.0.xlsx`. Validates clean under pyxform.

**`tests/test_new_modules.py`** covers the geometry constants, the canopy point layout, the sample size figures quoted in the review, and an end-to-end synthetic plot through `plot_metrics`. Five tests, all passing.

## Config changes

`plot:` now carries the nested geometry rather than the 1/7 acre plot. `split_sample:` is new and holds the Half A allocation by forest type and the seed offset. The `allocation:` block is unchanged and now describes Half B only; `notebooks/03_allocate_draw.ipynb` needs a cell added to write `allocation_typeA.csv` before `grts_split_draw.R` will run.
